# 실행 전 예측 (2026-10-20)
- P(기획서 복붙): 명시 규칙(T0,F1,F2,F4,F5,L1,L2)은 대부분 통과. 모호 4개(F3,F6,L3,L4)는 실행마다 다르게 해석 — 특히 F3(10만 경계)·L4(한도에 수수료 포함?)·L3(잔액에 수수료 포함?). 누락 C1(동시성)은 가끔 실패.
- D(기획서 + 개발 보강·예시 테스트): 대부분 13/13.
- 모델 차이보다 조건 차이가 클 것.
