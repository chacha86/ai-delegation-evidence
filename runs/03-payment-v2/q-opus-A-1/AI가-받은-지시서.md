## 기능
- 회원마다 지갑(잔액)이 있다. 처음 잔액은 0이다.
- 충전: `POST /api/v1/wallet/charge`, 요청 본문 `{"amount": 숫자}`
- 잔액 조회: `GET /api/v1/wallet` → 응답 JSON 에 `balance` 필드
- 글 작성(`POST /api/v1/posts`) 요청 본문에 `price`(숫자, 생략하면 0)를 받는다. price 가 0보다 크면 유료 글이다.
- 구매: `POST /api/v1/posts/{id}/purchase`
- 본문 열람: `GET /api/v1/posts/{id}/content` → 응답 JSON 에 `content` 필드
- 성공 응답은 2xx 상태 코드. 인증은 기존 방식 그대로 쓴다.

- `curl` 은 이 PC의 보안 정책으로 막혀 있다. **localhost** 에 띄운 앱을 확인하는 HTTP 호출은 Python 등 다른 도구로 해도 된다. 외부 주소로의 호출은 금지.
