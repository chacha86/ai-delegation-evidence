`C:\ctj\exp2\p-opus-C-1` 의 Spring Boot(Kotlin) 프로젝트에 유료 글 결제 기능을 추가해 주세요.

## 기능
- 회원마다 지갑(잔액)이 있다. 처음 잔액은 0이다.
- 충전: `POST /api/v1/wallet/charge`, 요청 본문 `{"amount": 숫자}`
- 잔액 조회: `GET /api/v1/wallet` → 응답 JSON 에 `balance` 필드
- 글 작성(`POST /api/v1/posts`) 요청 본문에 `price`(숫자, 생략하면 0)를 받는다. price 가 0보다 크면 유료 글이다.
- 구매: `POST /api/v1/posts/{id}/purchase`
- 본문 열람: `GET /api/v1/posts/{id}/content` → 응답 JSON 에 `content` 필드
- 성공 응답은 2xx 상태 코드. 인증은 기존 방식 그대로 쓴다.

## 정책 (반드시 지킬 것)
1. 충전 금액은 1 이상이어야 한다. 0이나 음수는 거부하고 잔액은 그대로 둔다.
2. 잔액이 가격보다 적으면 구매는 실패하고 잔액은 그대로다. 잔액은 절대 음수가 되지 않는다.
3. 같은 글은 한 번만 살 수 있다. 두 번째 구매는 실패하고 돈은 한 번만 빠진다.
4. 작성자는 자기 글을 살 수 없다(구매 실패, 잔액 그대로). 작성자는 구매하지 않아도 본문을 볼 수 있다.
5. 유료 글 본문은 작성자와 구매자만 볼 수 있다. 그 밖의 사람에게는 어떤 조회 API(글 목록·글 단건 조회 포함)로도 본문이 보이면 안 된다. 무료 글 본문은 로그인한 누구나 볼 수 있다.
6. 구매 금액은 작성자의 지갑에 들어간다.
7. 글 가격은 0 이상이어야 한다.
8. 여러 요청이 동시에 와도 위 규칙이 지켜져야 한다 (잔액 음수, 중복 차감, 충전 누락이 없어야 한다).
