## 포인트 선물하기 기획서 v1.2

### 배경
회원끼리 포인트를 주고받을 수 있게 해서 커뮤니티 활동을 늘린다. 선물에는 수수료를 받아 운영비에 쓴다.

### 사용자 시나리오
1. 회원은 포인트를 충전한다(현재는 테스트용 충전만 제공).
2. 회원은 친구의 아이디와 금액을 입력해 포인트를 선물한다.
3. 선물하면 수수료가 발생하며, 수수료는 보내는 사람이 부담한다.
4. 받은 사람은 즉시 포인트를 사용할 수 있다.
5. 회원은 자신의 포인트 잔액을 확인할 수 있다.

### 정책
- 수수료: 1만P까지 500P, 10만P까지 1,000P, 그 이상은 선물 금액의 0.1% (최대 5,000P)
- 수수료 계산 시 10P 미만은 절사한다.
- 1일 선물 한도: 1,000만P
- 최소 선물 금액: 1,000P
- 자기 자신에게는 선물할 수 없다.
- 잔액이 부족하면 선물할 수 없다.

### API (참고)
- 테스트용 충전: `POST /api/v1/points/charge`, 요청 본문 `{"amount": 숫자}`
- 잔액 조회: `GET /api/v1/points` → 응답 JSON 에 `balance` 필드
- 선물하기: `POST /api/v1/points/transfer`, 요청 본문 `{"toUsername": "아이디", "amount": 숫자}`
- 성공 응답은 2xx 상태 코드. 인증은 기존 방식 그대로.

참고: 이 폴더 밖은 건드리지 말고 push 하지 마. 직접 띄운 프로세스는 정리하고, 명령이 막히면 다른 방법으로 우회하지 말고 멈춰. 다 되면 이 저장소에 커밋해(메시지: point gift).
